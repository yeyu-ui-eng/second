# User Manual

## Getting Started

### Login

1. Navigate to the application URL
2. Enter your email and password
3. Click "Sign in"

### Dashboard

Your dashboard adapts to your role:

#### Sales Staff Dashboard
- **Total Sales**: Lifetime sales amount
- **Monthly Revenue**: Current month performance
- **Commission**: 5% of total sales
- **Active Orders**: Orders in progress
- **Recent Orders**: Your latest 10 orders

#### Production Staff Dashboard
- **Assigned**: Tasks assigned to you
- **In Progress**: Tasks you're working on
- **Completed**: Finished tasks
- **Delayed**: Tasks with delays

### Orders

#### Viewing Orders
1. Click "Orders" in the sidebar
2. Use the search bar to find orders by number or customer name
3. Filter by status using the dropdown
4. Click the eye icon to view order details

#### Creating Orders (Sales)
1. Click "New Order" button
2. Select customer from the dropdown
3. Select product (price auto-fills)
4. Enter quantity, size, color
5. Set due date if applicable
6. Add notes if needed
7. Click "Create Order"

#### Updating Orders
1. Open order detail page
2. Click "Edit" button
3. Update status, payment, quantity, or notes
4. Click "Save"

### Production Tasks

#### Viewing Tasks
1. Click "Production" in the sidebar
2. See all assigned tasks with current stage

#### Updating Stage
1. Click "Move to [next stage]" button
2. Stage automatically advances through the workflow
3. Use the detail view to add notes or delay reasons

### Profile

1. Click your avatar in the top-right corner
2. Select "Profile"
3. Update personal information
4. Change password if needed
